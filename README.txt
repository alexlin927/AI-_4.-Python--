Python 第四單元：統計處理與結果評估 — GitHub Pages 網頁版

共 50 頁，16:9 投影片，逐頁教師講稿。

上傳步驟：
1. 將 index.html、data.js、slides 整個資料夾上傳至 GitHub 儲存庫根目錄。
2. Settings → Pages → Deploy from a branch，選擇實際分支 main 或 master，目錄 /(root)。
3. 等部署成功後，開啟 https://帳號.github.io/儲存庫名稱/。

操作：方向鍵左右翻頁、Home/End 首尾頁、N 顯示講稿、F 全螢幕、G 開啟總覽。
網站不需要任何外部 JS 套件，可在電腦上直接雙擊 index.html 預覽。
